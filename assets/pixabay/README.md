# Football Dynasty — Pixabay media pack

This folder is reserved for locally bundled football photography and video used by the game.

## Approved source searches
- Football data / analytics: https://pixabay.com/images/search/football%20data/
- Football stadiums: https://pixabay.com/images/search/football-stadium/
- Soccer photography: https://pixabay.com/images/search/soccer/
- Football videos: https://pixabay.com/videos/search/football/

## Offline asset rules
1. Download the original asset from its individual Pixabay item page; do not hotlink search thumbnails.
2. Check the current Pixabay Content License and the individual item's availability before adding it.
3. Do not redistribute an asset as a standalone stock file or imply endorsement by its creator.
4. Keep the creator, item-page URL, download date, asset type, and licence review in `ATTRIBUTION.json`.
5. Optimise images to WebP/JPEG and videos to a compact MP4 format suitable for Android APK size.
6. Use local relative paths in the app so media works offline.
7. Never use sponsored iStock results as Pixabay assets.

## Planned asset groups
- `stadium/` — stadium and pitch backgrounds
- `matchday/` — football action and crowd photography
- `analytics/` — football data and tactical visuals
- `press/` — press conference / mixed-zone media
- `videos/` — licensed short football clips
